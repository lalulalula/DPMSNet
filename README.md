# DPMSNet

## Dataset

The datasets used in this project are available via Quark Cloud Drive:
- **Download:** [Quark Cloud Drive](https://pan.quark.cn/s/410a20f527bc)
- **Access code:** `KwdF`

## Training

```bash
python train.py --dataset_dir /path/to/datasets
```

## Testing

```bash
python test.py \
  --dataset_dir /path/to/datasets \
  --checkpoint /path/to/checkpoint.pth.tar
```
